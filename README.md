# discourse-bale-notifications
یک افزونه برای Discourse که به کاربران اجازه می‌دهد اعلان‌های خود را از طریق پیام بله دریافت کنند

# نصب کردن
1. افزونه را با استفاده از دستورالعمل‌های اینجا نصب کنید: [How to install a plugin](https://meta.discourse.org/t/install-a-plugin/19157)
2. با صحبت کردن با [BotFather](https://ble.ir/botfather) یک ربات بله بسازید.
3. «توکن» را در تنظیمات سایت در بخش «bale access token» قرار دهید
4. گزینهٔ «bale notifications enabled» را فعال کنید

به‌شدت توصیه می‌کنم از دستور `/setjoingroups` استفاده کنید تا امکان استفاده از ربات در چت‌های گروهی غیرفعال شود. این ربات برای استفاده در گروه‌ها طراحی نشده و ممکن است اطلاعاتی را که کاربران نباید به آن دسترسی داشته باشند، افشا کند (مثلاً نمی‌خواهید پیام‌های خصوصی به یک چت گروهی ارسال شوند). به‌عنوان یک لایه‌ی دفاعی اضافه، خود افزونه هم اکنون پیام‌های دریافتی از چت‌های غیرخصوصی (گروه/کانال) را به‌صورت برنامه‌نویسی‌شده نادیده می‌گیرد؛ با این‌حال اجرای `/setjoingroups` همچنان توصیه می‌شود.

می‌توانید نام/تصویر/توضیحات ربات خود را تنظیم کنید.

# دستور العمل دریافت اعلان
1. به تنظیمات کاربری خود در انجمن بروید، به بخش `Bale Notifications` بروید و روی دکمه‌ی «دریافت کد اتصال» بزنید. یک کد ۶ رقمی به شما نمایش داده می‌شود که تا ۱۵ دقیقه معتبر است.
2. همان کد را به‌عنوان یک پیام ساده برای ربات بله ارسال کنید.
3. اکنون باید اعلان‌ها را از طریق پیام بله دریافت کنید! برای قطع اتصال در هر زمان، به همان بخش تنظیمات کاربری برگردید و روی «قطع اتصال» بزنید.

> توجه امنیتی: در نسخه‌های قبلی، اتصال با وارد کردن دستی «Chat ID» خام (که ربات در پیام اول برمی‌گرداند) در پروفایل انجام می‌شد. از آنجا که Chat ID یک مقدار محرمانه‌ی طراحی‌شده نیست، این روش امکان اتصال نادرست/غیرمجاز به حساب کاربر دیگر را فراهم می‌کرد. روش جدید نیازمند تایید همزمان دسترسی به حساب دیسکورس (برای دریافت کد) و دسترسی به همان چت بله (برای ارسال کد) است.

# پوشش انواع اعلان
این افزونه همه‌ی انواع اعلان دیسکورس را پوشش نمی‌دهد - و نمی‌تواند بدهد، چون
هسته‌ی دیسکورس فقط برای مجموعه‌ی مشخصی از انواع اعلان، رویداد لازم برای این
افزونه را صادر می‌کند. فهرست دقیق انواع پشتیبانی‌شده/پشتیبانی‌نشده و دلیل هر
کدام در [NOTIFICATION_COVERAGE.md](./NOTIFICATION_COVERAGE.md) مستند شده است.

# پنل مدیریتی
از مسیر `/admin/plugins/bale-notifications` می‌توانید تعداد کاربران متصل،
وضعیت زنده‌ی وب‌هوک (از خودِ API بله)، فعالیت ارسال اخیر (موفق/ناموفق)، و یک
فرم برای ارسال پیام آزمایشی به یک کاربر مشخص ببینید.

# ترجیحات شخصی هر کاربر
هر کاربرِ متصل، علاوه بر تنظیم سراسری سایت (`bale_enabled_notification_types`)،
می‌تواند از میان همان انواعِ فعال‌شده در سایت، زیرمجموعه‌ی دلخواه خودش را در
تنظیمات کاربری‌اش انتخاب کند. اگر هیچ ترجیحی ثبت نکند، همه‌ی انواع فعالِ سایت
را دریافت می‌کند (رفتار پیش‌فرض).

# تنظیمات تکمیلی اختیاری
- **نمایش آواتار** (`bale_notifications_show_avatar`): اگر فعال شود، آواتار
  کاربر عامل اعلان به‌همراه متن (به‌صورت عکس+کپشن) ارسال می‌شود؛ اگر متن از
  محدودیت طول کپشن بله (۱۰۲۴ کاراکتر) بیشتر باشد، به‌صورت خودکار و امن به
  حالت متنی معمولی برمی‌گردد.
- **ساعات سکوت** (`bale_notifications_quiet_hours_enabled` و تنظیمات شروع/پایان):
  در این بازه، پیام‌ها همچنان کامل ارسال می‌شوند (چیزی از دست نمی‌رود)، فقط
  بی‌صدا (بدون لرزش/صدا روی گوشی) تحویل داده می‌شوند - بر اساس منطقه‌ی زمانی
  خودِ کاربر گیرنده در صورت تنظیم‌بودن، وگرنه منطقه‌ی زمانی پیش‌فرض سایت.
